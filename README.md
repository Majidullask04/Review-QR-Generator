# Review QR Generator

A simple React + Vite app that generates Google review QR codes from review links and lets users download them as PNG files.

## Features

- Paste a Google review URL or g.page link
- Validate that the URL is a valid Google review URL
- Generate a QR code with brand blue styling
- Download the QR as a PNG file
- Copy the original URL to clipboard
- View recent QR history saved in localStorage
- Responsive layout for mobile and desktop
- Print-friendly QR preview

## Tech Stack

- React
- Vite
- JavaScript
- QRCode library

## Project Setup

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Production Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Notes

This project is designed for generating QR codes for Google review links and sharing them with customers quickly.
